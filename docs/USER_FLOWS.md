# User Flows

Visitor → browse published opportunities → detailed brief → signup → apply/save/register.
Company → signup → organization → draft brief → review commercial-use disclosure → publish → review applicants → shortlist/accept → contract milestones.
Solver → profile skills → explainable matches → proposal → team → submission → portfolio evidence.
Organizer → own challenge → submissions → criteria/scores → explicit result publication (advanced judging UI pending).
Admin → provision role externally → reports/moderation. Public signup never accepts admin. AI → explicit configured provider → generated draft → user review → publication.
